# Blog Hero SVG Images

This directory contains 22 auto-generated SVG hero images for blog posts, organized by country theme.

## Overview

All SVG files are 960x480px with:
- Beautiful gradient backgrounds (darker to lighter within country theme)
- Subtle repeating geometric patterns (circles, hexagons, diagonal lines, dots, waves, or grids)
- Country emoji positioned subtly in background
- Accent color circles for visual depth
- Accent line at bottom for polish


## Design Features

Each SVG includes:
- **Primary Color**: Darker country theme color
- **Secondary Color**: Lighter shade for gradient
- **Accent Color**: Brightest shade for pattern details
- **Pattern**: Unique geometric pattern for visual variety
- **Emoji**: Country flag emoji at 15% opacity
- **Gradients**: Diagonal gradient from top-left to bottom-right

## File Size

All files are optimized and lightweight (~1.3-1.5 KB each).
