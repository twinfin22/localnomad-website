## Placement Recommendation

**Recommendation: Create a separate `media-sources.md` file**
**Path**: `localnomad-blog-plugin/skills/fact-checker/references/media-sources.md`

**Rejected alternative**: Appending to `government-sources-global.md`
**Why rejected**: The filename implies Tier 1 government sources. Adding media outlets creates ambiguity risk — a fact-checker agent reading the file may treat Tier 2 entries as Tier 1. Update cadences also differ: government domain URLs change rarely; media outlet ownership/reliability changes more frequently (see: SCMP 2015, Malay Mail 2018).

**Rationale for separate file**:
1. Name integrity — government-sources-global.md stays government-only
2. Maintenance isolation — media reliability assessments update more often than government URLs
3. Architectural consistency — parallel to the existing country-scoped Tier 1 file pattern
4. Load discipline — fact-checker can load media-sources.md alongside government-sources-global.md on every run (always needed for Type A stats and Type E attribution claims)

**Proposed section structure for media-sources.md**:
1. Brief usage instructions (5 lines)
2. Section A: International wire services + organizations (Reuters, AP, OECD, World Bank, IOM, UN DESA, IMF)
3. Section B: Country-specific media (Korea → Japan → Taiwan → China → Thailand → Vietnam → Indonesia → Malaysia → Singapore → Philippines)
4. Section C: Tier 3 sources with explicit use restrictions
5. Reliability update log (last reviewed date per outlet)

**Proposed column schema**:
```
| Source | URL | Tier | Reliability | Timeliness | Bias/Ownership | Best For |
```

## Key Findings Summary

[FINDING] 4 sources should be downgraded from proposed Tier 2 to Tier 3: Korea Bizwire (press release wire), Global Times (CCP propaganda), Numbeo (crowd-sourced), Nomad List (community estimates).
[STAT:n] n = 4 downgraded
[STAT:effect_size] 10% of all 41 assessed sources fail Tier 2 threshold

[FINDING] Vietnam has the weakest independent English-language media coverage of immigration topics — both available outlets (VnExpress, Vietnamnet) are state-affiliated, making Tier 1 government sources (immigration.gov.vn) the only reliable verification path for Vietnam claims.
[STAT:n] n = 2 Vietnam media sources assessed; both state-adjacent

[FINDING] For China immigration claims, SCMP and Caixin Global are the only credible Tier 2 independent sources. Global Times must be treated as Tier 3. NIA (en.nia.gov.cn) is strongly preferred as Tier 1 for any procedural claim.
[STAT:n] n = 3 China media sources assessed; 1 downgraded to Tier 3

[LIMITATION] This analysis covers English-language sources only. Some immigration policy details are only available in Korean (e.g., Hi Korea), Japanese (e.g., METI announcements), Traditional Chinese (NIA Taiwan), or Simplified Chinese (NIA China). The fact-checker skill already notes this limitation; the Tier 2 list does not solve it.

[LIMITATION] Paywalled sources (Nikkei Asia partial, Caixin Global partial, Straits Times partial, CommonWealth Magazine partial) reduce practical usability for automated fact-checking. The firecrawl_scrape tool may not bypass paywalls — manual verification may be required for paywalled content.
