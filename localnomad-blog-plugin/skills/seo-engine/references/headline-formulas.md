# Headline Formulas — SEO-First + LibaD Adaptation

## 7 Base Formulas (from content-creation)

Each formula has a corporate original and a LibaD-adapted version.

### 1. How-To
- Corporate: "How to [achieve result] [without common obstacle]"
- LibaD: "I [achieved result] [without common obstacle]. Here's How."
- Example: "I Got My Korea E-7 Visa Without an Agency. Here's How."

### 2. Number List
- Corporate: "[Number] [adjective] ways to [achieve result]"
- LibaD: "[Number] Things Nobody Told Me About [topic]"
- Example: "5 Things Nobody Told Me About Taiwan's Gold Card"

### 3. Contrarian
- Corporate: "Why [common belief] is wrong (and what to do instead)"
- LibaD: "[Common belief] Is a Lie. Here's What's Actually Happening."
- Example: "The Korea D-8 Visa Is Easy? That's a Lie."

### 4. Complete Guide
- Corporate: "The [adjective] guide to [topic]"
- LibaD: "Everything I Learned About [topic] (The Hard Way)"
- Example: "Everything I Learned About Japan's DN Visa (The Hard Way)"

### 5. Do This Not That
- Corporate: "[Do this], not [that]"
- LibaD: "I [did this] Instead of [that]. Here's Why."
- Example: "I Chose the F-1-D Over the E-7. Here's Why."

### 6. Lesson Learned
- Corporate: "What [impressive result] taught us about [topic]"
- LibaD: "What [number] [experience] Taught Me About [topic]"
- Example: "What 3 Rejected Applications Taught Me About Korean Immigration"

### 7. Year Update
- Corporate: "[topic]: what [audience] needs to know in [year]"
- LibaD: "[topic] in [year]: What Actually Changed"
- Example: "Korea E-7 Visa in 2026: What Actually Changed"

## Generation Rules

When generating headline options:
1. Start with primary keyword — it MUST appear in the headline
2. Keep ≤70 characters (hard limit — allows LibaD's narrative style while staying SERP-safe)
3. Generate 3 options:
   - Option A: SEO-optimized (keyword prominent, clear structure)
   - Option B: LibaD-flavored (personal, 1st person, question or story)
   - Option C: Hybrid (keyword present + LibaD tone)
4. At least 1 option should be question-based (LibaD pattern)

## Validation

- [ ] Primary keyword present in all 3 options
- [ ] All options ≤70 characters
- [ ] ≥1 uses personal/1st person framing
- [ ] ≥1 is question-based or story-based
