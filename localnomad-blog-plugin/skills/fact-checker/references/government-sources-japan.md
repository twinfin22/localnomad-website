# Government Sources — Japan

Last updated: 2026-03-13

Use this as the authoritative list of Tier 1 sources when verifying Japan-related claims. Any URL on this list is automatically Tier 1. URLs NOT on this list require manual tier classification.

---

| Source | URL | Covers |
|--------|-----|--------|
| ISA (Immigration Services Agency) | isa.go.jp | Residence status, visa procedures |
| ISA (EN) | isa.go.jp/en/ | English version |
| MOJ ISA page | moj.go.jp/isa/ | Ministry of Justice immigration section |
| MOFA | mofa.go.jp | Visa issuance at embassies |
| MOFA Visa Info | mofa.go.jp/j_info/visit/visa/ | Visa types and application procedures |
| Japanese Law Translation | japaneselawtranslation.go.jp | Official English translations of immigration law |
| e-Gov | e-gov.go.jp | Laws, regulations, Cabinet Orders |
| SSW Portal | ssw.go.jp | Specified Skilled Worker program (ISA operated) |
| DN Visa (ISA) | moj.go.jp/isa/applications/status/designatedactivities53_00001.html | Digital Nomad Visa specifics |
| DN Visa (MOFA) | mofa.go.jp/ca/fna/pagewe_000001_00046.html | DN Visa embassy guidance |

**Japan-specific notes**:
- ISA = residence status (in Japan). MOFA = visa issuance (at embassies abroad). Different jurisdictions.
- Digital Nomad Visa official name: "Designated Activities (Notification 53)"
- SSW1 and SSW2 are separate categories with different rules
