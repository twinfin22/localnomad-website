# Government Sources — Korea

Last updated: 2026-03-13

Use this as the authoritative list of Tier 1 sources when verifying Korea-related claims. Any URL on this list is automatically Tier 1. URLs NOT on this list require manual tier classification.

---

| Source | URL | Covers |
|--------|-----|--------|
| Immigration Service (MOJ) | immigration.go.kr | Visa types, residence status, policy announcements |
| Immigration Service (EN) | immigration.go.kr/immigration_eng/ | English version (less detail than KR) |
| HiKorea | hikorea.go.kr | Online applications, appointment scheduling, ARC status |
| Korean Law DB | law.go.kr | Immigration Control Act, Enforcement Rules, all statutes |
| Korean Law DB (EN) | law.go.kr/LSW/eng/ | English translations of Korean law |
| MOFA | mofa.go.kr | Visa applications via embassies, consular services |
| MOFA Overseas Missions | overseas.mofa.go.kr | Regional embassy/consulate pages |
| Gov.kr Foreigners | gov.kr/portal/foreigner/ | General immigration info portal |
| E-Arrival Card | e-arrivalcard.go.kr | Online arrival card system |
| National Tax Service | nts.go.kr | Tax rules for foreign residents |
| Visa Navigator | visa.go.kr | Visa type search/navigator tool |
| KIIP (사회통합프로그램) | socinet.go.kr | Social Integration Program registration, classes |
| Study in Korea | studyinkorea.go.kr | Student visa (D-2) info, university certification |

**Korea-specific notes**:
- MOJ press releases count as Tier 1 (K-STAR, Top-Tier, and other programs are announced this way)
- Check immigration.go.kr announcement section (공지사항) for recent policy changes
- Visa sub-category codes matter: F-2-7 vs F-2-T are different pathways
- HiKorea = service portal (applications), immigration.go.kr = information portal (rules)
- KIIP test portal: kiiptest.org (placement tests) — also Tier 1 (run by MOJ)
- ⚠️ visa-kr.com, visa-korea.com 등은 사칭 사이트. 반드시 .go.kr 확인
