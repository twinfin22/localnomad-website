# Government Sources — Taiwan

Last updated: 2026-03-13

Use this as the authoritative list of Tier 1 sources when verifying Taiwan-related claims. Any URL on this list is automatically Tier 1. URLs NOT on this list require manual tier classification.

---

| Source | URL | Covers |
|--------|-----|--------|
| NIA | immigration.gov.tw | Residence permits, ARC, work permits |
| NIA (EN) | immigration.gov.tw/7120/ | English version |
| BOCA | boca.gov.tw | Entry visas, visitor/resident visas |
| BOCA Visa Info | boca.gov.tw/np-137-2.html | Visa categories and requirements |
| BOCA eVisa | visawebapp.boca.gov.tw/BOCA_EVISA/ | Online eVisa applications |
| Gold Card Portal | goldcard.nat.gov.tw | Employment Gold Card program |
| NIA Gold Card | coa.immigration.gov.tw/coa-frontend/four-in-one/entry/golden-card | Gold Card application portal |
| MOFA | en.mofa.gov.tw | Consular services, embassy guidance |
| Taiwan Law DB | law.moj.gov.tw/ENG/ | Immigration Act (English), enforcement rules |
| Immigration Act | law.moj.gov.tw/ENG/LawClass/LawAll.aspx?pcode=D0080132 | Full Immigration Act text |
| Digital Nomad Visa (NDC) | digitalnomad.ndc.gov.tw | Official DNV portal (National Development Council) |
| BOCA DNV page | boca.gov.tw/cp-158-7718-c0382-2.html | BOCA's Digital Nomad Visa info |

**Taiwan-specific notes**:
- NIA = residence (in Taiwan). BOCA = entry visas (at TECO offices abroad).
- Gold Card portal is authoritative for Gold Card specifics — cross-reference with NIA
- DNV: primary source is digitalnomad.ndc.gov.tw (NDC), cross-reference with BOCA page
- **Legal requirement**: Taiwan content must NOT use "qualify," "eligible," "recommended." See legal-bright-lines skill.
- Cite specific Immigration Act article numbers when referencing law (e.g., "Article 25 of the Immigration Act")
- 2024 amendments: 63 clauses changed with relaxed stay/residency rules
