# Media & Community Sources — Tier 2 and Tier 3

Last updated: 2026-03-14

This file lists curated non-government sources for fact-checking. Tier 2 sources can verify Type A (statistics) and E (attribution) claims. Tier 2 sources are NOT sufficient alone for Type B (requirements) or D (policy) claims — those require Tier 1 government sources.

---

## How to Use

1. Tier 2 = established media with editorial standards. Acceptable as secondary verification.
2. Tier 3 = community/expert sources. Use only for context, not as primary verification.
3. Sources marked ⚠️ have known editorial caveats — read the note before citing.

## Usage Rules for Fact-Checker

1. **Type B (Requirements) and Type D (Policy)**: MUST have Tier 1 source. Tier 2 is supplementary only.
2. **Type A (Statistics)**: Tier 2 acceptable if citing original data source (e.g., Korea Herald citing KOSTAT data).
3. **Type C (Process)**: Tier 2 acceptable for general process descriptions. Tier 3 acceptable for "how it works in practice" context.
4. **Type E (Attribution)**: Tier 2 is the expected source (quoting media articles).
5. **Tier 3 sources**: Never link as primary source in blog posts. Acceptable as "community perspective" or "practical tip" framing only.
