## 채널 구조 (초기 — 최소한으로 시작)

> 📘 **원칙**: 채널은 적게 시작하고, 대화가 활발해지면 분리한다. 텅 빈 채널 10개보다 활발한 채널 5개가 낫다.

### 카테고리 1: START HERE
| 채널 | 용도 | 설정 |
|------|------|------|
| `#welcome` | 자동 환영 메시지 + 서버 가이드 | Read-only (관리자만 작성) |
| `#introduce-yourself` | 자기소개 (어디서 왔는지, 뭐하는지, 어디 거주/계획 중인지) | 모두 작성 가능 |
| `#rules` | 커뮤니티 규칙 | Read-only |

### 카테고리 2: NOMAD LIFE
| 채널 | 용도 |
|------|------|
| `#visa-talk` | 비자 관련 질문, 경험 공유 (웹사이트 콘텐츠 연결) |
| `#neighborhoods` | 동네 추천, 집 구하기, 살아본 후기 |
| `#coworking-cafes` | 코워킹/카페 추천, 와이파이 리뷰 |
| `#general` | 그 외 모든 대화 |

### 카테고리 3: CITIES
| 채널 | 용도 |
|------|------|
| `#seoul` | 서울 관련 모든 대화 |
| `#tokyo` | 도쿄 관련 |
| `#taipei` | 타이베이 관련 |

> 오사카, 후쿠오카, 가오슝 등은 해당 도시에 사람이 모이면 추가. 처음부터 만들지 않는다.

### 카테고리 5: RESOURCES
| 채널 | 용도 |
|------|------|

1. Be respectful — we're all figuring this out together
2. No spam or self-promotion without asking (one-time project share in #general is fine)

4. Keep city-specific chat in the right channel
5. No recruiting or job posting outside #jobs-gigs
6. English is the default language — other language channels will be added as the community grows

These rules exist to keep this space useful. If something feels off, DM @Admin.

## 성장 전략

### 초기 씨앗 (0~50명)
1. 기존 왓츠앱 30명에게 "디스코드에도 들어와라, 비자 정보 아카이브가 여기 있다" 안내
2. 밋업 참석자에게 디스코드 초대 링크 공유
3. 웹사이트에서 유입 (비자 페이지 → 디스코드 CTA)

### 성장기 (50~200명)
4. Reddit r/digitalnomad, r/korea, r/japanlife 등에서 유용한 답변 달고 디스코드 언급
5. 밋업 사진/후기를 인스타/X에 올리면서 디스코드 링크
6. 웹사이트 블로그 포스트에 디스코드 CTA 삽입

### 확장기 (200명+)
7. 도시별 밋업 오거나이저 모집 (도쿄, 타이베이)
8. 디스코드 이벤트 기능으로 온라인 밋업 (Q&A, AMA)
9. 코워킹 스페이스 사전 관심 조사 → 얼리 액세스 → 디스코드 멤버 우선

## 왓츠앱과의 관계 정리

| | 왓츠앱 | 디스코드 |
|---|---|---|
| **접근** | 밋업 참석자만 (비공개) | 누구나 (공개) |
| **용도** | 실시간 밋업 조율, 소규모 대화 | 비자 정보, 동네 후기, 질문, 아카이브 |
| **톤** | 친구들 사이 캐주얼 | 열린 커뮤니티, 약간 더 구조적 |
| **전환** | 유지 (256명 한도까지) | 메인 커뮤니티로 성장 |

핵심: 왓츠앱은 "이너서클", 디스코드는 "프론트도어". 둘은 경쟁이 아니라 보완 관계.
