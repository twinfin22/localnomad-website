# LocalNomad Brand Guide

## Brand Name
- **"LocalNomad"** — Always one word, camelCase capitalization
- Plural: "LocalNomads"
- Domain: `localnomad.club`
- Never: "Local Nomad", "Local Nomad Club", "local nomad"

## Brand Color

| Token | Hex | Usage |
|-------|-----|-------|
| **Primary** | `#1B4965` | Logo, headings, primary CTAs, nav |
| Primary Light | `#2A6F97` | Hover states, secondary elements |
| Primary Dark | `#122F42` | Footer, dark accents |
| Neutral 900 | `#1A1A1A` | Body text |
| Neutral 100 | `#F5F5F5` | Backgrounds |
| White | `#FFFFFF` | Card backgrounds, reversed text on primary |

### Rationale
Deep Teal Navy (`#1B4965`) — 남색에 초록기가 살짝 섞여 "여행/탐험" 느낌을 가미하면서도 비자 정보 플랫폼에 필요한 신뢰감을 유지. 순수 네이비보다 딱딱하지 않고, 밝은 블루보다 무게감이 있음.

## Logo

### Wordmark
- **"Local"**: Serif typeface (Playfair Display, Lora, DM Serif Display, or Source Serif 4)
- **"Nomad"**: Sans-serif typeface (DM Sans, Inter, Poppins, Montserrat, or Outfit)
- 두 파트의 굵기(weight)는 동일 — 대비는 serif vs sans-serif 글자 형태에서만
- Color: `#1B4965` on white, or white on `#1B4965`
- No icons, no tagline in logo lockup

### Favicon
- Option B: 45° 기울어진 다이아몬드, 한쪽 반만 채색
- Option C: 위쪽 반원 나침반 + 바늘 (떠오르는 해/나침반 이중 의미)
- Color: `#1B4965` solid
- Must be legible at 16×16px

## Typography (Web)

| Element | Font | Weight | Size |
|---------|------|--------|------|
| H1 | Serif (matches "Local" in logo) | 700 | 2.5rem |
| H2–H3 | Sans-serif (matches "Nomad" in logo) | 600 | 1.5–2rem |
| Body | Inter or system sans-serif | 400 | 1rem |
| Caption | Inter or system sans-serif | 400 | 0.875rem |

## Voice & Tone
- 친근하면서 프로페셔널 (friendly but professional)
- 정보 제공자이지 법률 자문이 아님 (informational, never advisory)
- 비자 용어는 정확하게, 설명은 쉽게 (precise terms, plain language)
