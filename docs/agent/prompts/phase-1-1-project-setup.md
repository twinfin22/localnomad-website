## Step 4: Project structure

Create the following structure. **All new components are Server Components by default** (no "use client" unless explicitly needed).

```
app/
  layout.tsx              ← Root layout (Lora font import, metadata)
  globals.css             ← Global styles (Tailwind base + brand colors)
  page.tsx                ← Root redirect to /en
  [locale]/
    layout.tsx            ← i18n layout (NextIntlClientProvider)
    page.tsx              ← Landing page (hero)
    [country]/
      visa/
        [type]/
          page.tsx        ← Visa detail page (skeleton for now)
components/
  ui/                     ← shadcn/ui (auto-generated, DO NOT MODIFY)
  landing/
    hero.tsx              ← Hero section (Server Component)
    country-card.tsx      ← Korea/Taiwan selection card
lib/
  utils.ts                ← cn() utility (auto-generated by shadcn)
messages/
  en.json                 ← English translations
  ja.json                 ← Japanese (skeleton)
  zh-tw.json              ← Traditional Chinese (skeleton)
  vi.json                 ← Vietnamese (skeleton)
```

**Design rules**:
- No images or illustrations. Typography + color only.
- Must fit in one viewport on mobile (no scroll to see CTA)
- CTA cards: white background, rounded corners, subtle elevation on hover
- Touch targets minimum 44px, spacing 8px+
- Minimum font size 16px

**Country cards link to**:
- Korea → `/en/korea` (placeholder page for now)
- Taiwan → `/en/taiwan` (placeholder page for now)
