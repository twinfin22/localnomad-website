  Permanent Residence (10-year standard route)

CHINA VISA TRANSITIONS
═══════════════════════════════════════════════════════════════════

PATHWAY 1: Graduate → Talent → Permanent Residence (Preferred)
──────────────────────────────────────────────────────────────

  Student (X1)
   180+ days study
      ↓ (with job offer)
  Z Visa (Work)
   90 days - 5 years
      ↓ (if recognized as high-level talent)
  R Visa (Talent)
   5-10 years, 180 days per entry
      ↓
  Permanent Residence
   (criteria vary by province)

  Time to PR: 3-8 years typical, unclear official timeline

───────────────────────────────────────────────────────────────────────────

PATHWAY 2: Direct Talent Recognition
───────────────────────────────────────

  Skilled Specialist
      ↓ (with government talent confirmation)
  R Visa (Talent)
   5-10 years, 180 days per entry
      ↓
  Permanent Residence
   (preferred pathway for high-value contributors)

  Characteristics: Faster than Z → PR, government-backed status

───────────────────────────────────────────────────────────────────────────

CRITICAL CONSTRAINT: Cannot change visa status while in China
─────────────────────────────────────────────────────────────

  On X1 Student?
      ↓ (Must exit China)
  Apply for Z Visa abroad

  On Z Visa?
      ↓ (Must exit China)
  Apply for R Visa abroad

  No in-country status changes allowed

IMPLEMENTATION NOTES
═════════════════════════════════════════════════════════════════════════════

Each visa JSON file contains:
  - type: visa identifier (e.g., "engineer-specialist")
  - pathsTo[]: array of visas reachable FROM this visa
  - pathsFrom[]: array of visas that can transition TO this visa

Example:
  {
    "type": "engineer-specialist",
    "pathsTo": ["student-visa"],
    "pathsFrom": ["hsw", "business-manager", "permanent-jp"]
  }

This structure enables:
  1. Forward navigation: "What can I transition to from Engineer visa?"
  2. Reverse navigation: "What visas can I use to reach this visa?"
  3. Path building: Chain multiple transitions together
  4. UI visualization: Draw transition graphs/flowcharts
